## Цель работы

Закрепить навыки использования Dependency Injection (DI), интерфейсов, регистрации сервисов и встроенного механизма логирования ASP.NET Core.

## Задание

Создайте ASP.NET Core приложение для работы с информацией о студентах.

### 1. Создайте модель Student

- `Id` — идентификатор;
- `Name` — имя студента;
- `Group` — группа.

### 2. Создайте сервис для работы со студентами

Создайте интерфейс `IStudentService` с методами:

```csharp
IEnumerable<Student> GetAll();
Student? GetById(int id);
```

Создайте класс `StudentService`, который реализует `IStudentService`. Добавьте в него минимум 3 студентов.

### 3. Зарегистрируйте зависимость

Зарегистрируйте сервис в `Program.cs` с использованием одного из изученных жизненных циклов:

```csharp
builder.Services.AddTransient<IStudentService, StudentService>();
```

### 4. Используйте Dependency Injection

Создайте `StudentsController`. Получите `IStudentService` через Constructor Injection, не создавая объект сервиса вручную через `new`:

```csharp
private readonly IStudentService _studentService;

public StudentsController(IStudentService studentService)
{
    _studentService = studentService;
}
```

Реализуйте два метода:

- `GET /api/students` — получить всех студентов.
- `GET /api/students/{id}` — получить студента по его идентификатору. Если студент отсутствует — `404 Not Found`.

### 5. Добавьте логирование

Внедрите в контроллер `ILogger<StudentsController>`. Добавьте минимум 3 сообщения журнала разных типов:

```csharp
_logger.LogInformation(...);
_logger.LogWarning(...);
_logger.LogError(...);
```

Например: Information — запрос списка студентов; Warning — студент с указанным Id не найден; Error — возникла ошибка при выполнении операции. Используйте шаблоны сообщений:

```csharp
_logger.LogWarning(
    "Student with ID {StudentId} was not found",
    id);
```

### 6. Проверьте работу приложения

Запустите приложение и через Swagger: получите список студентов; получите существующего студента по Id; запросите несуществующий Id и убедитесь, что API возвращает 404 Not Found; проверьте появление соответствующих сообщений в логах.

## Что необходимо сдать

- Исходный код проекта.
- Скриншот регистрации `IStudentService` в `Program.cs`.
- Скриншот Swagger с результатом GET.
- Скриншот ответа 404 Not Found.
- Скриншот консоли или Output с сообщениями журнала.
